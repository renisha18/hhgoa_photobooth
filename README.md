# HH Goa 2026 Builder ID

A mobile-first Builder ID generator for HH Goa 2026. Users can upload and reposition a photo, add their name and role, choose a generated builder title and card theme, download a 1080 × 1350 PNG, and share it from supported mobile devices.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Deploy to Vercel

1. Upload this folder to a GitHub repository.
2. Open `https://vercel.com/new`.
3. Import the repository.
4. Keep the detected framework as **Next.js**.
5. Click **Deploy**.

No environment variables, database, or server-side storage are required. Photos remain in the user's browser.
